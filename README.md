# Simple Interest Calculator

## Project Description
This project contains a Bash script that calculates **Simple Interest** based on user input.

## Features
- Takes Principal amount as input
- Takes Rate of Interest as input
- Takes Time Period as input
- Calculates and displays the Simple Interest

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Run
```bash
bash simple-interest.sh
```
